# Tika

티켓 기반 칸반 보드 TODO 앱 (Next.js App Router).

## 스크립트

```bash
npm run dev          # 개발 서버 실행
npm run build         # 프로덕션 빌드
npm run start         # 프로덕션 서버 실행
npm test              # Jest 테스트 실행
npm run test:watch    # Jest watch 모드
npm run lint          # ESLint 검사
npm run db:generate    # Drizzle migration 파일 생성
npm run db:migrate    # Drizzle migration 적용
npm run db:push       # 스키마를 DB에 직접 반영
npm run db:studio     # Drizzle Studio 실행
```

프로젝트 구조 및 컨벤션은 [CLAUDE.md](./CLAUDE.md), 상세 명세는 [docs/](./docs)를 참조.
